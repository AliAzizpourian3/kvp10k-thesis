\chapter{Literature Review}
\label{ch:literature}

\section{Document Understanding}
\label{sec:doc_understanding}

Document understanding — the task of extracting structured information from unstructured document images — is a foundational problem in information extraction and enterprise automation. Early systems relied on hand-crafted rules; modern approaches leverage deep learning and pre-training to achieve better generalization.

Early document understanding systems relied on hand-crafted rules and template matching, where documents were processed using predefined spatial zones or keyword dictionaries. OCR engines such as Tesseract provided raw text extraction, but structural understanding — identifying which text belongs to which field — required manual layout rules per document type. These systems generalize poorly: a rule designed for one invoice format breaks on a different vendor's layout. Heuristic approaches such as regular expressions or nearest-neighbor text pairing remain useful lower bounds but cannot handle layout diversity at scale.

Convolutional neural networks were first applied to document images for classification tasks, treating the document as a visual object. Recurrent models such as LSTMs were later used to model sequential token dependencies in OCR output. A major shift came with the Transformer architecture, which replaced recurrence with self-attention for sequence modelling~\cite{vaswani2017attention}. Later document models extended this architecture to combine textual information with layout and visual features.

\section{Multimodal Pre-training for Documents}
\label{sec:multimodal}

Multimodal pre-training in the document domain seeks to learn joint representations of text, layout, and visual information, enabling transfer learning to downstream tasks. The LayoutLM family has become a prominent architecture family in this area.

LayoutLM~\cite{layoutlm} was the first model to jointly pre-train text and 2D layout information for document understanding. It extends BERT by adding 2D positional embeddings derived from bounding box coordinates, allowing the model to learn spatial relationships between tokens. Pre-trained on IIT-CDIP with masked language modeling, it achieved strong results on form understanding benchmarks including FUNSD and SROIE~\cite{sroie}. LayoutLM demonstrated that layout is a first-class feature for document tasks, not merely an accessory to text.

LayoutLMv2~\cite{layoutlmv2} extended the original by incorporating visual features from the document image using a CNN backbone, enabling true multimodal fusion of text, layout, and vision within a single pre-training objective. It introduced a spatial-aware self-attention mechanism that conditions attention on relative 2D positions between tokens, rather than only adding absolute position embeddings. LayoutLMv2 reported improvements on the document-understanding benchmarks evaluated in the original study.

LayoutLMv3~\cite{layoutlmv3} unifies text and image representation through a single transformer backbone, replacing the CNN visual encoder with patch-based image embeddings similar to Vision Transformers~\cite{vit}. Pre-training objectives include Masked Language Modeling, Masked Image Modeling, and Word-Patch Alignment, enabling the model to learn fine-grained correspondence between text tokens and image regions. LayoutLMv3 achieved state-of-the-art results on FUNSD, CORD, and DocVQA at the time of its release, and serves as the encoder backbone in the proposed architecture of this thesis.

\section{Key-Value Pair Extraction}
\label{sec:kvp_extraction}

Key-value pair extraction is the core task addressed in this thesis: given a document image, extract structured pairs of semantically-linked keys and values with spatial localization. Multiple algorithmic approaches have emerged, each with distinct trade-offs.

A common paradigm for key-value extraction treats the problem as token classification using BIO tagging schemes (Begin, Inside, Outside), where each token is labeled as the beginning or continuation of a key or value span. Models such as LayoutLM and LayoutLMv2 are typically fine-tuned in this manner on datasets like FUNSD. Many sequence-labeling formulations use predefined semantic categories and therefore depend on a task-specific label schema. A generic key/value labeling scheme can identify open-vocabulary spans, but it still requires a separate mechanism to determine which keys and values are linked.

Generative approaches formulate extraction as a text generation task: given a document's text and layout representation as input, the model generates all key-value pairs as a structured output string. This framing allows open-vocabulary extraction without a predefined field schema. The published KVP10k baseline~\cite{kvp10k} uses an LMDX-like document representation and fine-tunes Mistral-7B~\cite{mistral} to generate structured entries containing the KVP type, text, and bounding boxes. Our reconstructed Stage~3 implementation instead serializes predictions as Python list-of-lists representations. Generative models offer flexible open-vocabulary output, but their generated text is not constrained to tokens observed in the extracted input, so unsupported output is possible.

Parameter-efficient fine-tuning provides a practical way to adapt large language models without updating all model parameters. LoRA introduces trainable low-rank matrices into selected model layers while keeping the pretrained weights fixed, reducing the number of trainable parameters. QLoRA further combines low-rank adaptation with a quantized base model to reduce memory requirements during fine-tuning. This approach is used for the reconstructed Mistral baseline in this thesis~\cite{lora,qlora}.

Graph neural networks have been applied to document understanding by treating detected text regions as nodes and spatial or semantic proximity as edges. Models such as PICK~\cite{pick} construct document graphs and propagate information between nodes to infer key-value relationships. These approaches can naturally model non-local dependencies but require graph construction as a preprocessing step.

\subsection{Entity Linking Approaches}
\label{subsec:entity_linking}

A distinct line of work formulates key-value extraction as an entity linking problem: first identify entity spans (keys and values), then predict which spans are semantically linked. This two-stage decomposition separates the ``what'' (entity recognition) from the ``who-with-whom'' (relationship prediction), enabling specialised modules for each sub-task.

SPADE (Spatial Dependency Parsing for Semi-Structured Document Information Extraction)~\cite{spade} formulates document information extraction as dependency parsing over OCR tokens. It predicts directed token relations for serialization and field assignment, and for grouping fields into a structured output graph. This formulation supports complex two-dimensional layouts and hierarchical information without requiring a fixed one-dimensional token order. SPADE reports results on several semi-structured document datasets, including receipts, name cards, invoices, and forms. It provides methodological context for relation-based document extraction, but the contiguous KEY/VALUE span grouping used in our V2 architecture is a separate implementation decision (Section~\ref{sec:v2-span-linking}).

BROS (BERT Relying On Spatiality)~\cite{bros} is a pre-trained language model that combines text with relative two-dimensional spatial information. It encodes relative positions using corresponding vertices of text-block bounding boxes and introduces area-masked language modelling as a pre-training objective. For downstream entity-linking tasks, the study applies an adapted SPADE decoder that predicts relations between document tokens. BROS reports results on FUNSD, SROIE, CORD, and SciTSR without using document-image features. Its relative spatial encoding, area-masking strategy, and relation-based decoder provide methodological context for this thesis, but they do not define our exact span grouping or candidate-reduction design (Section~\ref{sec:v2-span-linking}).

Neural relation models commonly score pairs of representations using learned interaction functions. Biaffine scoring has been used successfully for structured relation prediction, while scaled dot-product attention provides a simpler projected similarity mechanism. These formulations provide methodological context for the evolution from the initial biaffine linker to the projected scaled-dot-product relation scorer evaluated in this thesis~\cite{dozat2017biaffine,vaswani2017attention}.

More recent relation-focused methods further show that strong entity representations alone do not resolve document relation extraction. GeoLayoutLM explicitly pre-trains geometric relations and relation heads~\cite{geolayoutlm}; KVPFormer casts keys as questions and predicts values through a coarse-to-fine decoder with a spatial compatibility bias~\cite{kvpformer}; and LayoutPointer combines relative 2D context and adaptive spatial constraints with a pointer-based relation formulation for multi-line entities~\cite{layoutpointer}. Collectively, these methods motivate objectives and decoders designed specifically for spatial entity association rather than treating linking as a lightweight extension of entity recognition.

\section{Information Extraction from Forms}
\label{sec:form_extraction}

Form and receipt understanding represent important specialized domains within document information extraction, where the goal is to extract and link key-value pairs from scanned or digital forms, invoices, and receipts. These domains have motivated substantial recent research.

FUNSD (Form Understanding in Noisy Scanned Documents, Jaume et al., 2019)~\cite{funsd} is a benchmark of 199 noisy scanned forms with entity labeling and linking annotations, widely used to evaluate form understanding models. CORD (Consolidated Receipt OCR Dataset, Park et al., 2019)~\cite{cord} collected more than 11,000 Indonesian receipts; the released annotated benchmark contains 1,000 samples with OCR and semantic parsing annotations. FUNSD and CORD are widely used benchmarks for evaluating document-understanding models, including models from the LayoutLM family. Their document types --- forms and receipts --- overlap substantially with the KVP10k categories evaluated in this thesis.

Receipt understanding is a practically important subtask of document information extraction, where the goal is to extract structured fields such as merchant name, date, total amount, and line items from point-of-sale receipts. Receipts present a relatively constrained layout compared to general business documents, making them an accessible entry point for document understanding research. However, real-world receipts vary considerably in quality, language, and format, motivating the inclusion of receipt samples in large-scale diverse benchmarks such as KVP10k.

\section{Evaluation Metrics}
\label{sec:metrics_review}

Rigorous evaluation of information extraction systems requires metrics that capture both textual correctness and spatial accuracy of extracted spans. The KVP10k benchmark combines Normalized Edit Distance (NED) for text matching with Intersection over Union (IoU) for spatial matching and macro-averages precision and recall per page. The paper specifies NED~$<0.2$ and IoU~$>0.3$; its released evaluator implements the IoU boundary inclusively ($\geq0.3$). This thesis follows the executable benchmark for reported comparisons and records the discrepancy explicitly. Formal definitions appear in Section~\ref{sec:evaluation-protocol}.

\section{Related Datasets}
\label{sec:related_datasets}

Multiple benchmarks have been introduced for document understanding and information extraction, each emphasizing different aspects of the problem space.

KVP10k~\cite{kvp10k} is a large-scale benchmark for open-vocabulary key-value pair extraction from business documents, introduced at ICDAR 2024. It contains 10,707 unique pages (9,656 training and 1,051 test pages) spanning invoices, forms, and receipts collected from real-world sources by IBM Research. Its released data include 48,280 training and 5,255 test annotation rows because pages have multiple annotator copies. Each page includes polygon bounding box annotations and explicit linking attributes connecting keys to their corresponding values. Of the 1,051 test pages, 581 were usable in this thesis after data preparation; the experiments therefore evaluate this subset rather than the complete test split. Unlike FUNSD and CORD, KVP10k provides both a large-scale training set and an official evaluation benchmark with a Mistral-7B generative baseline. These properties make KVP10k a suitable benchmark for the task studied in this thesis.

DocVQA~\cite{docvqa} (Document Visual Question Answering, Mathew et al., 2021) frames document understanding as visual question answering over document images, testing a model's ability to locate and extract specific information given a natural language question. RVL-CDIP~\cite{rvlcdip} is a large-scale document classification benchmark of 400,000 scanned document images across 16 categories. XFUND~\cite{xfund} extends form understanding to seven non-English languages. While these datasets are not directly used in this thesis, they represent the broader evaluation landscape within which the KVP10k benchmark is positioned.

\section{Scope of Experimental Design}
\label{sec:experimental_scope}

The experimental design was scoped at project start to a LayoutLMv3 encoder
with a learned relation linker and the KVP10k Mistral baseline. Although other
relation-extraction architectures were available, implementing and evaluating
them would have required separate model designs and full experimental
pipelines. They are therefore included as methodological context and future
alternatives rather than additional experimental baselines.

\section{Summary, Research Gaps, and Thesis Scope}
\label{sec:lit_summary}

The review motivates the following research gaps and thesis objectives:

\begin{enumerate}
    \item \textbf{Controlled evaluation and diagnosis on KVP10k}: This thesis evaluates a LayoutLMv3-based discriminative linker on KVP10k using the released benchmark evaluator, examines token-level and span-level candidate formation through validation diagnostics, and diagnoses data-pipeline limitations and relation-modelling limitations within the current projected scaled-dot-product linker pipeline.
    
    \item \textbf{Spatial localisation and text accuracy}: The benchmark reports text-only, location-only, and text+location metrics. This thesis uses these metrics to describe the corresponding performance differences for the reconstructed Mistral baseline and V4.
    
    \item \textbf{Systematic error analysis by annotation geometry}: This thesis further examines how performance varies across exploratory page-level clusters based on annotation-box count, size, and spatial spread.
    
    \item \textbf{Learned linking for key-value association}: SPADE~\cite{spade} provides token-relation graph modelling, while BROS~\cite{bros} combines relative spatial representations and area-masked pre-training with a SPADE-based relation decoder; neither approach has been evaluated on the larger and more diverse KVP10k benchmark. This thesis examines how token-level and span-level candidate construction changes the candidate-space imbalance and diagnoses linking behaviour within the present KVP10k pipeline.
\end{enumerate}

In this thesis, we adopt LayoutLMv3 as the encoder backbone combined with a learned span-level projected scaled-dot-product linker with spatial features. We investigate both token-level (V1) and span-level (V2) linking granularities. SPADE and BROS provide context for relation-based extraction and spatial representations, while contiguous span grouping and its candidate reduction are design choices of the present KVP10k pipeline.
