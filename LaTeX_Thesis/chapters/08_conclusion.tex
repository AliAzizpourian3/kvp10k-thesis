\chapter{Conclusion}
\label{ch:conclusion}

This thesis studied key--value pair extraction from business documents through
dataset analysis, a reconstructed generative reference system, and a
layout-aware discriminative pipeline. It characterised annotation geometry on
9{,}124 unique coordinate-bearing KVP10k training pages and performed a
separate exploratory spatial-link audit. It also implemented and evaluated a
task-specific discriminative pipeline around the pretrained LayoutLMv3 encoder
and reconstructed a Mistral-7B reference system based on the published KVP10k
approach. The detailed distinction between thesis contributions and prior
resources is given in Section~\ref{sec:contributions}.

The controlled evaluation compared the final LayoutLMv3-based span-level
discriminative model (V4) with the reconstructed Mistral-7B reference system on
the same 581 prepared test pages. V4 reaches Regular text+location F1 of
$0.329$, compared with $0.657$ for the reconstructed reference system. The
development diagnostics and qualitative analysis examine candidate
construction, span formation, relation supervision, and relation selection.
Because several pipeline changes were introduced together, the thesis does not
assign an isolated causal effect to any one change.

\section{Research Questions Revisited}
\label{sec:rq_revisited}

The research questions introduced in Section~\ref{sec:research_questions} are
revisited below.

\subsection{RQ1: Annotation Geometry}

KVP10k pages vary in annotation count, box size, and spatial spread. The
analysis identifies two weakly separated annotation-geometry strata:
Cluster~0 has more boxes and a broader spatial distribution, while Cluster~1
has fewer, larger boxes in a more compact region. The silhouette coefficient
of $0.222$ indicates weak cluster separation. Because the clustering uses
annotation geometry rather than semantic document labels, these exploratory
groups must not be interpreted as document genres. The separate spatial-link
audit reports a mean normalised
centre distance of $0.120$. These findings motivate relative spatial features
and geometry-stratified robustness checks, but they do not show that spatial
features causally improve model performance.

\subsection{RQ2: Same-Subset System Comparison}

On the same prepared 581-page test subset, the reconstructed Mistral-7B
reference system reaches Regular text+location F1 of $0.657$, compared with
$0.329$ for V4. The reconstructed reference system is therefore stronger under
the shared evaluation protocol. This system-specific result does not establish
that generative models are generally superior to discriminative models because
the systems differ in model capacity, training coverage, training objective,
and output representation.

\subsection{RQ3: Development Diagnostics}

V1 forms a dense token-level candidate space, whereas the span-level V2 and V4
paths are designed to reduce the candidate space and use a unit closer to the
annotated relation. However, the preserved development paths also differ in
span source, bounding-box filtering, and relation-label construction. The
diagnostics therefore do not isolate the causal effect of token-level versus
span-level linking. They instead show that candidate construction, span
formation, and relation supervision must be aligned before a granularity
comparison can be interpreted reliably.

\subsection{RQ4: Success and Failure Factors}

Performance varies descriptively across the annotation-geometry strata: V4 is
stronger in Cluster~1, while the reconstructed Mistral-7B reference system is
stronger in Cluster~0. The weak cluster separation and absence of a causal
intervention prevent attribution to a specific layout feature. The qualitative
cases identify two failure routes: a missing or merged entity span can remove
the intended relation from the candidate set, while competing plausible spans
can lead to an incorrect relation selection.

On validation data, V4 reaches token-level entity micro F1 of $0.813$ and
Regular text+location pair F1 of $0.331$. These metrics use different units,
but their difference supports the conclusion that the transition from entity
classification to complete pair extraction is a major internal limitation. It
does not isolate the linker from upstream label and span errors. The direct V4
decoder emits Regular pairs only and therefore provides no direct Unkeyed or
Unvalued coverage.

Future work should use controlled ablations that retain the final coordinate
mapping and fixed data splits while separating span source, bounding-box
filtering, relation-label construction, and linker design. It should also test
structured or constrained relation decoding, deliberately selected hard
negatives, explicit row and column relations, direct Unkeyed and Unvalued
prediction, and probability calibration. Longer-input, multi-page, and rendered
document-image experiments are needed to evaluate the remaining input and
visual limitations.

Overall, the reconstructed Mistral-7B reference system is stronger than V4
under the shared evaluation protocol. The central scientific takeaway is that
extracting plausible key and value entities is insufficient for complete KVP
extraction: the system must also construct the correct spans and select the
correct relations between them.
