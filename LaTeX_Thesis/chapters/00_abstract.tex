  \bfseries
  {\selectlanguage{english}Abstract}
\end{center}
\normalfont

\vspace{0.5cm}

This thesis investigates automatic key-value pair extraction from business documents using generative and layout-aware discriminative approaches. The discriminative system combines a LayoutLMv3-base encoder, token classification, and span-level key-value linking. It uses extracted text and bounding boxes with a constant blank visual input and therefore does not use document-specific image information. The final V4 model is selected on validation Regular text+location macro F1 and evaluated on the held-out KVP10k test set using the released benchmark protocol. V4 achieves Regular F1 scores of 0.392 for text, 0.446 for location, and 0.345 for combined text+location matching. Its entity-classification micro and macro F1 scores are 0.792 and 0.772, respectively. The reconstructed Mistral baseline achieves a higher Regular text+location F1 of 0.521. The gap between entity recognition and final pair extraction, supported by qualitative error analysis, indicates that relation linking remains the main limitation of the discriminative pipeline. Overall, the results show that LayoutLMv3 provides strong entity recognition from text and layout alone, but more effective relation modelling is required to close the gap to the generative baseline.
